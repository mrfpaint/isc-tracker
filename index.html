📋 IT Admin Setup Guide
1
Open Azure Portal
Go to portal.azure.com and sign in with MRF admin account.
2
Create App Registration
App Registrations → New Registration → Name: "ISC Tracker" → Register.
3
Add Redirect URI
Authentication → Add platform → Single-page application (SPA) → paste the URL of this app → Save.
4
Add API Permissions
API Permissions → Add → Microsoft Graph → Delegated permissions → add:
Files.ReadWrite.All   User.Read
5
Create Excel File on OneDrive
Create ISC-Tracker-Data.xlsx on the admin's OneDrive root with 3 sheets: Users, ASMs, Entries (with headers in Row 1).
6
Paste Tenant ID & Client ID above → Test
Click Save Configuration → click Test Connection → sign in with MRF admin account in the popup → green = connected! ✅
